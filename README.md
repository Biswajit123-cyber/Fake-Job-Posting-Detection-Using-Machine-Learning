# Fake-Job-Posting-Detection-Using-Machine-Learning
  Fake Job Posting Detection Using Machine Learning

## Project Overview

The **Fake Job Posting Detection Using Machine Learning** project aims to identify potentially fraudulent job advertisements using machine learning techniques and text analysis. It helps users assess job posting credibility and recognize suspicious employment opportunities.

**Objectives**

- Detect potentially fake job postings using machine learning.
- Analyze job descriptions and textual information.
- Apply data preprocessing and feature extraction techniques.
- Classify job advertisements as potentially fraudulent or legitimate.
- Support safer and more informed job searches.

 **Technologies Used**

- **Programming Language:** Python
- **Machine Learning:** Scikit-learn
- **Data Analysis:** Pandas, NumPy
- **Text Processing:** TF-IDF (if implemented)
- **Web Application:** Streamlit (if implemented)
- **Development Environment:** Jupyter Notebook, VS Code

** Project Workflow**

1. Dataset collection
2. Data cleaning and preprocessing
3. Exploratory data analysis
4. Text preprocessing and feature extraction
5. Machine learning model training
6. Model evaluation
7. Job posting prediction

** Key Features**

- Job posting text analysis
- Machine learning-based classification
- Identification of potentially suspicious job advertisements
- Prediction results for submitted job information
- A foundation for improving job scam awareness
